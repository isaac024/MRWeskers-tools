# KARDS overlay (KardsTracker)

A deck tracker overlay for the card game KARDS, built with Electron and OCR.

**No installer yet.** For now this folder holds the source as
[KardsTracker.zip](KardsTracker.zip) (snapshot of 2025-08-01, without
`node_modules`).

## Run from the zip

1. Install [Node.js](https://nodejs.org/) (LTS).
2. Unzip `KardsTracker.zip` and open a terminal in that folder.
3. `npm install`, then `npm start`.
